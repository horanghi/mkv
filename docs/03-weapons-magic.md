# 03. 무기 & 마법

## 3.1 설계 원칙

1. **완벽한 무기는 없다** — 모든 무기에 명확한 약점을 둔다
2. **쓰레기 무기도 없다** — 원작의 횃불처럼 "뽑으면 죽는" 무기를 만들지 않는다
3. **선택은 되돌릴 수 있다** — 무기 상자는 스테이지당 3~4개 배치, 교체 자유
4. **각성으로 성격이 바뀐다** — 성유물 갑옷 착용 시 무기가 다른 무기처럼 변한다

## 3.2 무기 7종

### 기본 데이터

| 무기 | 데미지 | 연사 간격 | 투사체 속도 | 궤도 | 동시 발사 | 특성 |
|---|---|---|---|---|---|---|
| **창** Lance | 10 | 20f | 320 px/s | 직선 | 2 | 밸런스 · 기본 무기 |
| **단검** Dagger | 6 | 10f | 400 px/s | 직선 | **3** | 최고 연사 · 저데미지 |
| **횃불** Torch | 8 + 4/초 | 30f | 200 px/s | 포물선 | 2 | 착탄 시 화염 장판 3초 |
| **도끼** Axe | 22 | 36f | 240 px/s | 포물선 | 2 | 최고 단발 · 느림 |
| **십자가** Cross | 14 | 28f | 280 px/s | 직선 | 2 | **관통** · 성속성 |
| **원반** Discus | 9 | 24f | 300 px/s | 벽 반사 | 2 | 최대 4회 반사 · 화면 체류 |
| **망치** Hammer | 16 | 32f | 260 px/s | 포물선 | 2 | 착지 시 충격파 (반경 40px, 12뎀) |

> 데미지 기준: 일반 좀비 HP 20, 스테이지 1 보스 HP 300.

### 무기별 상세

#### 창 (Lance) — 기본 무기
직선으로 빠르게 날아간다. 특별할 것 없지만 어떤 상황에서도 나쁘지 않다.
**약점**: 어디에도 특화되지 않음. 후반 대형 적 앞에서 화력 부족.
**플레이버**: *"왕국 대장간의 마지막 작품."*

#### 단검 (Dagger) — 연사형
3발 동시 발사. 압박이 강하고 회피 후 반격에 최적.
**약점**: 데미지가 낮아 방어력 높은 적(갑옷 기사, 골렘)에게 무력.
**플레이버**: *"빠르지만, 얕다."*

#### 횃불 (Torch) — 지역 제어
포물선으로 날아가 착지 지점에 3초간 화염 장판 생성. 장판은 지형을 따라 흐른다.
**원작 재해석**: 원작 최악의 무기를 **지역 장악형 유틸**로 재설계.
좁은 통로, 적 스폰 지점, 보스 이동 경로 봉쇄에 강하다.
**약점**: 즉발 화력 없음. 공중 적에게 거의 무의미.
**플레이버**: *"불은 기다릴 줄 안다."*

#### 도끼 (Axe) — 한 방
가장 높은 단발 데미지. 큰 포물선으로 날아간다.
**약점**: 느리고 궤도 예측이 어려워 근거리 대응 최악.
**플레이버**: *"한 번에 끝낼 자신이 있다면."*

#### 십자가 (Cross) — 성속성 관통
적을 관통하며 직선으로 날아간다. 언데드 계열(스테이지 1·4·5 다수)에게 **데미지 1.5배**.
**최종보스 필수 조건** — 루시안에게 데미지를 줄 수 있는 유일한 무기. 원작 계승.
**약점**: 획득 위치가 제한적. 언데드가 아닌 적에게는 평범.
**플레이버**: *"신은 이곳까지 오지 않았다. 상징만 남았다."*

> **십자가 필수 조건의 함정 방지**
> 원작에서 이 규칙은 악명 높은 불친절이었다. 우리는 사전 경고를 둔다:
> 스테이지 6 진입 시 벽화에 십자가 문양 + 최종 구역 문에 "성물 없이는 열리지 않는다" 시각 표시.
> 십자가 없이 최종 구역에 도달하면 직전 체크포인트에 십자가 상자가 강제 스폰된다.

#### 원반 (Discus) — 반사
벽과 천장에 튕기며 화면에 오래 머문다. 최대 4회 반사 후 소멸.
좁은 지형에서 폭발적인 누적 데미지.
**약점**: 개활지에서는 그냥 날아가 버림. 궤도 통제 난이도 높음.
**플레이버**: *"닫힌 방에서 가장 잔인하다."*

#### 망치 (Hammer) — 충격파
포물선으로 날아가 지면 착탄 시 좌우 충격파. 지상 적 광역 처리.
**약점**: 공중 적에게 직격만 유효. 충격파는 지형 단차를 넘지 못함.
**플레이버**: *"땅이 먼저 비명을 지른다."*

## 3.3 무기 각성 — 성유물 갑옷 착용 시

성유물 갑옷을 입으면 모든 무기가 각성 형태로 변한다.
**어떤 갑옷을 입었는지에 따라 각성 방향이 달라진다.**

### 황금 갑옷 각성 — 화력

| 무기 | 각성 효과 |
|---|---|
| 창 | 3연사 황금 창격, 데미지 12 |
| 단검 | 5발 부채꼴 |
| 횃불 | 장판 지속 6초 + 화염 기둥 발생 |
| 도끼 | 회전 도끼 — 관통 + 귀환 |
| 십자가 | 십자 폭발 (착탄 시 십자 형태 광역) |
| 원반 | 반사 8회 + 반사마다 데미지 +2 |
| 망치 | 충격파 반경 2배 + 상승 파편 |

### 은 갑옷 각성 — 방어·유틸

| 무기 | 각성 효과 |
|---|---|
| 창 | 투사체가 적 투사체를 상쇄 |
| 단검 | 적중 시 서리 — 적 이동 속도 40% 감소 |
| 횃불 | 화염 장판이 아군 보호막으로 전환 (투사체 차단) |
| 도끼 | 적중 시 3초 빙결 |
| 십자가 | 관통 궤적에 성벽 잔상 (2초간 투사체 차단) |
| 원반 | 랜슬 주위를 공전하는 궤도 원반 |
| 망치 | 착지 시 얼음 기둥 생성 (발판으로 사용 가능) |

### 수정 갑옷 각성 — 속도

| 무기 | 각성 효과 |
|---|---|
| 창 | 연사 간격 20f → 10f |
| 단검 | 동시 발사 3 → 6 |
| 횃불 | 즉발 화염탄으로 변화 (포물선 → 직선) |
| 도끼 | 투사체 속도 2배 + 잔상 |
| 십자가 | 발사 즉시 화면 끝까지 도달하는 광선 |
| 원반 | 원반 2개 동시 발사 |
| 망치 | 던지지 않고 근접 휘두르기 (즉발, 후딜 없음) |

> 각성은 **21가지 조합**을 만든다. 실질적으로 무기 7종이 아니라 28종이다.
> 에셋 비용은 색상 팔레트 스왑 + 파티클 변경으로 대부분 흡수 가능하다.

## 3.4 성흔 마법 (Sigil)

성유물 갑옷 착용 시에만 사용 가능. **쿨다운 12초**, 스테이지 이동 시 초기화.

### 광휘 (Radiance) — 황금 갑옷

- 화면 전체 백색 섬광, 0.4초 지속
- 잡몹 즉사, 보스에게 데미지 40 + 2초 경직
- **연출**: 화면 전체 화이트아웃 → 실루엣만 남았다가 복귀. 블룸 임계값 일시 0으로

### 성벽 (Aegis) — 은 갑옷

- 랜슬 주위 3초간 무적 방벽
- 방벽에 닿은 적 투사체는 **반사**되어 발사자에게 되돌아감
- **연출**: 육각 결정 방벽 + 굴절 셰이더. 반사 시 각 투사체에 잔상

### 균열 (Rift) — 수정 갑옷

- 4초간 적·투사체 속도 30%로 감소 (랜슬은 정상 속도)
- **연출**: 화면 전체 채도 하강 + 시간 잔상 + 저역 필터 오디오

## 3.5 무기 획득 & 교체

| 항목 | 설계 |
|---|---|
| 획득 방식 | 보물상자 (파괴 시 무작위 무기 1종 드롭) |
| 상자 배치 | 스테이지당 3~4개 |
| 드롭 가중치 | 미보유 무기 우선 (동일 무기 반복 방지) |
| 교체 | 드롭된 무기 위를 지나가면 즉시 교체 |
| 되돌리기 | **3초 유예** — 잘못 밟았으면 이전 무기가 그 자리에 남아있다 |
| 사망 시 | 현재 무기 유지 (체크포인트 재시작) |
| 컨티뉴 시 | 창으로 초기화 |

> **"3초 유예"는 반드시 넣는다.**
> 원작에서 원치 않는 무기를 밟아 런이 망가지는 것은 가장 흔한 이탈 원인이었다.

### 함정 상자

일부 상자에는 **마법사(Wizard)** 가 들어있다. 파괴 시 튀어나와 랜슬을 변신시킨다.

| 변신 | 지속 | 상태 |
|---|---|---|
| 개구리 | 8초 | 공격 불가, 점프만 가능, 이동 속도 50% |
| 노인 | 8초 | 이동 속도 40%, 공격은 가능 |

원작의 악명 높은 요소를 계승하되 **지속 시간을 명시하고 타이머를 UI에 표시**한다.
불합리함이 아니라 "긴장되는 8초"가 되도록.
