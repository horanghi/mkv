# 마령촌 (魔靈村) / GRIMHOLLOW — 게임 기획서

> 마계촌(Ghosts 'n Goblins) 계보를 잇는 웹 기반 하드코어 2D 액션 플랫포머
> 코드명: `mkv` · 문서 버전 v0.1 · 2026-08-17

---

## 한 줄 컨셉

> **한 대 맞으면 갑옷이 부서지고, 두 대 맞으면 뼈만 남는다. 그 죽음마저 눈부시게.**

원작의 잔혹한 규칙은 그대로 두되, **피격과 죽음의 순간을 게임에서 가장 화려한 연출**로 뒤집는다.
좌절이 스펙터클이 되는 순간, 플레이어는 다시 시작 버튼을 누른다.

---

## 확정 사항

| 항목 | 결정 |
|---|---|
| 플랫폼 | 웹 브라우저 (데스크톱 우선, Vercel 배포) |
| 아트 스타일 | 모던 픽셀아트 + 셰이더 이펙트 폭발 |
| 게임 구조 | 원작형 선형 스테이지 클리어 + 2회차 진 엔딩 |
| 기술 스택 | TypeScript + PixiJS v8 (WebGL2/WebGPU) + Vite |
| 목표 플레이타임 | 1회차 ~90분 / 진 엔딩 ~3시간 |

## 원작 대비 결정 요약

| 원작 마계촌 | 마령촌의 선택 | 이유 |
|---|---|---|
| 고정 점프 궤도 (공중 제어 불가) | **유지** | 시리즈 정체성. 이걸 없애면 다른 게임이 됨 |
| 상·하 공격 불가 | **완화** (상단/하단 공격 허용) | 불합리한 난이도이지 좋은 난이도가 아님 |
| 갑옷→속옷→사망 (2피격) | **유지** + 성유물 갑옷으로 1회 유예 | 긴장감의 근원. 성유물은 보상형 유예 |
| 엄격한 시간 제한 | **완화** (스테이지당 여유 30%↑) | 시간 압박은 학습을 방해함 |
| 2회차 강제 (진 엔딩) | **유지 + 강화** (환마계) | 최고의 차별점이자 볼륨 2배 확보 수단 |
| 십자가 없이 최종보스 격파 불가 | **유지** | 시리즈 전통. 단, 사전 힌트 제공 |
| 무기 5종 | **7종** | 원작 5 + Resurrection 계승 2 |
