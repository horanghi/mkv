# 01. 컨셉 & 세계관

## 1.1 게임 정체성

| 항목 | 내용 |
|---|---|
| 타이틀 | **마령촌 (魔靈村)** / 영문 **GRIMHOLLOW** |
| 장르 | 2D 사이드스크롤 액션 플랫포머 (아케이드 하드코어) |
| 플랫폼 | 웹 브라우저 (데스크톱 우선, 게임패드 지원) |
| 시점 | 2D 측면 스크롤, 논리 해상도 480×270 |
| 세션 길이 | 1스테이지 8~12분 / 1회차(8스테이지) 2시간 / 진 엔딩 4시간 |
| 가격 모델 | 무료 웹 공개 (추후 Steam 확장 시 유료 검토) |

> 타이틀은 가안이다. `마령촌` 외 후보: `겁화촌`, `환마촌`, `명계촌`.
> 영문 `GRIMHOLLOW`는 "음산한 골짜기 마을"과 "공허"의 이중 의미를 노렸다.

## 1.2 핵심 재미 3축

### 축 1 — 정밀 점프의 긴장

공중에서 방향을 바꿀 수 없다. 점프하는 순간 착지점이 확정된다.
따라서 **뛰기 전에 읽어야 한다.** 이것이 마계촌의 본질이며, 우리는 이것을 버리지 않는다.

대신 **불합리한 부분만 걷어낸다**: 코요테 타임, 점프 버퍼, 상하 공격 허용.
"내가 잘못 판단했다"는 남기고 "게임이 나를 속였다"는 지운다.

### 축 2 — 성유물 갑옷의 스펙터클

피격은 이 게임에서 가장 화려한 순간이다.
0.18초 히트스톱, 24개 금속 파편, 방사형 섬광, 크로매틱 애버레이션.
플레이어는 갑옷을 잃고도 **"방금 그거 멋있었는데"** 라고 느낀다.

죽음을 벌칙이 아니라 볼거리로 만드는 것 — 하드코어 게임이 웹에서 살아남는 유일한 길이다.
상세: [06. 비주얼 디렉션](06-visual-direction.md#63-갑옷-파괴-연출)

### 축 3 — 2회차 환마계(幻魔界)

원작의 "이 방은 사탄이 만든 환각의 방이었다"를 계승하되, 단순 반복이 아니다.
같은 스테이지가 **색채 반전, 진행 방향 반전, 적 배치 재구성, 신규 기믹**으로 완전히 다른 게임이 된다.
에셋 재사용률을 극대화하면서 볼륨을 2배로 확보하는 설계이기도 하다.

## 1.3 타겟 플레이어

### 1차 타겟 — "그 시절을 아는 사람"
- 30~45세, 마계촌·록맨·악마성을 오락실/패미컴에서 경험
- 브라우저에서 바로 실행되는 접근성에 반응
- 클리어보다 "그 감각을 다시 느끼는 것"이 목적

### 2차 타겟 — "짧고 강한 도전을 원하는 사람"
- 20~35세, 블라스퍼머스·컵헤드·할로우 나이트 경험자
- 스트리밍/숏폼에 적합한 "죽는 순간이 예쁜 게임"에 반응
- 클립 공유 가능성이 유입 동력

### 명시적 비타겟
- 서사 중심 어드벤처를 원하는 플레이어
- 모바일 캐주얼 유저 (초기 범위 밖 — 조작 정밀도 요구가 큼)

## 1.4 스토리

### 로그라인

> 왕국 마지막 성기사 **랜슬**은 마계로 걸어 들어간 공주를 쫓는다.
> 공주는 납치된 것이 아니었다.

### 설정

**랜슬 경 (Sir Lancel), 32세**
왕국 최후의 성기사. 성유물 갑옷을 다루는 유일한 생존자.
과묵하고, 대사가 거의 없으며, 표정 대신 갑옷 상태로 감정을 드러낸다.

**이졸데 공주 (Princess Isolde), 24세**
마령촌의 문을 스스로 열고 걸어 들어갔다.
왕국을 덮친 역병의 근원이 왕가의 죄임을 알고, 그것을 끝내려 마왕과 거래하려 한다.

**대마왕 아스모데우스 (Asmodeus)**
1회차 최종보스. 마령촌의 지배자. 이졸데의 거래 상대.

**루시안 (Lucian)**
2회차 진 최종보스. 아스모데우스보다 상위의 존재.
마령촌 전체가 그가 만든 환영이었음이 드러난다.

### 서사 전달 방식

**컷신 없음.** 문서를 읽게 하지 않는다. 대신:

| 수단 | 예시 |
|---|---|
| 배경 스토리텔링 | 스테이지 2 마을의 불탄 집 안, 벽에 새겨진 왕가 문장 |
| 보스 등장 연출 | 갈라드(S5 보스)는 랜슬과 같은 갑옷을 입고 있다 — 대사 없이 관계가 전달됨 |
| 아이템 설명문 | 무기·갑옷 획득 시 한 줄 플레이버 텍스트 |
| 엔딩 차등 | 1회차 = 공주 구출 실패 암시 / 2회차 = 진실 공개 |

### 1회차 엔딩 (원작 오마주)

아스모데우스 격파 → 이졸데에게 도달 → 화면이 일그러지며

> *"이 마을은 처음부터 존재하지 않았다."*

→ 환마계 모드 강제 진입. 원작의 "사탄이 만든 환각의 방" 구조를 그대로 계승한다.

## 1.5 차별점 — 왜 이 게임인가

| 경쟁작 | 그들의 강점 | 마령촌의 위치 |
|---|---|---|
| 원작 마계촌 시리즈 | 정통성, 브랜드 | 원작의 불합리만 제거, 연출은 30년치 진보 |
| Blasphemous | 압도적 아트, 서사 | 우리는 서사 대신 **속도와 반응성**에 투자 |
| Dead Cells | 무한 리플레이 | 우리는 **수제작 스테이지의 밀도** |
| Cuphead | 보스 러시의 쾌감 | 우리는 **플랫포밍과 보스의 균형** |

### 웹 플랫폼이 주는 고유 이점
1. **클릭 한 번에 시작** — 하드코어 게임의 최대 장벽인 "설치"를 제거
2. **클립 공유 즉시성** — 죽는 순간 자동 GIF 저장 → 공유 (M4 검토)
3. **패치 즉시 반영** — 밸런스 조정이 배포 한 번

### 웹 플랫폼의 제약과 대응
| 제약 | 대응 |
|---|---|
| 초기 로드 용량 | 스테이지별 지연 로딩, 첫 플레이까지 8MB 이내 |
| 성능 편차 | 셰이더 품질 3단계 자동 감지 + 수동 조정 |
| 입력 지연 | 픽스드 타임스텝 60Hz + 입력 폴링 최우선 처리 |
| 저장 신뢰성 | localStorage + 수동 백업 코드 내보내기 |
