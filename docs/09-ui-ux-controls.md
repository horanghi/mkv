# 09. UI/UX & 조작

## 9.1 입력 매핑

### 키보드 (기본)

| 동작 | 기본 키 | 대체 |
|---|---|---|
| 이동 | ← → | A D |
| 위 (상단 공격 / 사다리) | ↑ | W |
| 아래 (웅크리기 / 사다리) | ↓ | S |
| 점프 | Z | Space |
| 공격 | X | J |
| 성흔 마법 | C | K |
| 일시정지 | Esc | Enter |
| 빠른 재시작 | R | — |

### 게임패드 (Gamepad API)

| 동작 | Xbox | PlayStation |
|---|---|---|
| 이동 | 좌스틱 / D-Pad | 좌스틱 / D-Pad |
| 점프 | A | ✕ |
| 공격 | X | □ |
| 성흔 마법 | RB / RT | R1 / R2 |
| 일시정지 | Start | Options |
| 빠른 재시작 | Back 길게 | Share 길게 |

**D-Pad 우선.** 아날로그 스틱은 데드존 0.4, 8방향 스냅 처리.
정밀 플랫포머에서 아날로그 입력은 오히려 방해가 된다.

### 입력 처리 요구사항

| 항목 | 스펙 |
|---|---|
| 폴링 | 프레임당 1회, 로직 갱신 최우선 |
| 입력 지연 | 총 2프레임(33ms) 이내 목표 |
| 동시 입력 | 좌+우 동시 입력 시 **나중에 누른 쪽** 우선 |
| 버퍼 | 점프 6프레임, 공격 4프레임 |
| 브라우저 대응 | `preventDefault` 로 스크롤·방향키 기본 동작 차단 |

## 9.2 HUD

```
┌──────────────────────────────────────────────┐
│ ♦♦♦  [창]                       04:12  128,400│  ← 상단바 (높이 24px)
│      ████████████████████░░░░░░░░░░░          │  ← 보스 HP (조건부)
│                                               │
│                    (게임 화면)                 │
│                                               │
│                                               │
│                         [C] ●●●○○○○○○○○       │  ← 마법 쿨다운 (조건부)
└──────────────────────────────────────────────┘
```

| 요소 | 위치 | 표시 조건 |
|---|---|---|
| 잔기 (♦) | 좌상단 | 상시 |
| 현재 무기 아이콘 | 잔기 우측 | 상시 |
| 남은 시간 | 우상단 | 상시. 30초 이하 시 적색 맥동 |
| 점수 | 시간 우측 | 상시 |
| 마법 쿨다운 | 우하단 | **성유물 갑옷 착용 시에만** |
| 변신 타이머 | 화면 중앙 하단 | 개구리/노인 상태에서만 |
| 보스 HP 게이지 | **상단바 바로 아래** | 보스전에서만 |

### HUD 원칙

1. **갑옷 상태는 HUD에 표시하지 않는다** — 랜슬 스프라이트가 곧 체력 게이지
2. **상시 요소는 4개 이하** — 잔기, 무기, 시간, 점수
3. **전투 중 HUD는 반투명 처리하지 않는다** — 픽셀아트에서 반투명은 지저분해진다
4. **필요할 때만 나타난다** — 마법 쿨다운, 보스 게이지, 변신 타이머는 조건부

> **보스 게이지가 위로 올라온 이유.** 처음에는 화면 하단이었다. 바닥에 깔면
> 보스와 플레이어가 있는 곳에서 눈을 떼야 읽힌다 — 이 장르에서 보스 게이지는
> 위에 있고, 위쪽은 이미 시간·점수를 보러 가는 자리다. 두께는 6px 로 상단바
> (24px)보다 얇게 두어 상시 정보와 구분한다.

### HUD 자동 숨김

3초간 아무 이벤트가 없고 적이 없으면 HUD 알파 60%로 감소.
경치 좋은 구간에서 화면을 최대한 보여주기 위함.

## 9.3 화면 흐름

```
[부트/로딩] → [타이틀] → [메인 메뉴]
                            ├─ 이어하기 → [게임]
                            ├─ 새 게임 → [난이도 선택] → [게임]
                            ├─ 보스 러시 (해금 시)
                            ├─ 갤러리 (해금 시)
                            └─ 설정
```

### 타이틀 화면

- 배경: 마령촌 원경 실루엣 + 번개 (7초 주기)
- 로고: 픽셀 로고 + 발광 셰이더
- **10초 무입력 시** → 어트랙트 모드 (게임플레이 데모 30초, 원작 오마주)

### 일시정지

| 항목 | 동작 |
|---|---|
| 배경 | 게임 화면 유지 + 블러 + 채도 40% |
| 메뉴 | 계속 / 재시작 / **난이도 3단계** / 조작법 |
| 복귀 | **3-2-1 카운트다운** 후 재개 |

> **구현 (`src/game/pause.ts` · `src/ui/menus/pauseMenu.ts`)**
>
> "타이틀로" 는 두지 않았다 — M1 에 그 화면이 없다. 없는 곳으로 가는 버튼을
> 만드는 것보다 없는 편이 낫다. 설정 중에서는 **난이도**만 넣었다(docs/08 8.4).
> 조작법은 9.6 이 정한 대로 항상 띄운다.
>
> 난이도를 바꾸면 판이 다시 시작된다. 도중에 체크포인트 수가 바뀌면 이미
> 지나온 구간의 규칙이 달라져 기록이 뒤섞이기 때문이다.
>
> 카운트다운에 넣는 시간은 **100ms 로 자른다.** 탭에서 돌아온 첫 프레임은
> 수 초짜리라, 그대로 넣으면 3-2-1 이 한 프레임에 소진되어 손을 올리기 전에
> 게임이 시작된다.
>
> 일시정지는 계측에도 걸린다. 이게 없으면 자리를 뜬 테스터가 그냥 죽고,
> 그 죽음이 "이탈" 로 잡혀 재시도율이 거짓으로 낮아진다. → prompts/m1-gate.md

### 사망 → 재시작 (최우선 UX)

**목표: 사망 판정부터 조작 가능까지 3초 이내.**

| 시각 | 이벤트 |
|---|---|
| 0.00s | 사망 판정, 히트스톱 250ms |
| 0.25s | 백골화 + 슬로우모션 1초 |
| 1.25s | 페이드 아웃 0.3초 |
| 1.55s | 체크포인트 위치로 이동, 페이드 인 0.3초 |
| 1.85s | 리스폰 무적 시작, **조작 가능** |

**게임 오버 화면은 잔기가 0일 때만 표시한다.**
잔기가 남아있으면 어떤 UI도 끼어들지 않는다.

> **구현 (`src/ui/menus/gameOverScreen.ts`)**
>
> 잔기가 0 이 되면 월드가 **멈추고 기다린다.** 예전에는 조용히 자동 컨티뉴되어
> 화면이 아예 없었다 — `showsGameOver` 가 쓰이지 않는 export 로 남아 있었다.
>
> 이어하기는 마지막 체크포인트에서 재개하고 잔기·무기를 초기화한다.
> **지나온 거리는 잃지 않는다.**
>
> 계측에 걸리지 않게 해 뒀다: 화면이 떠 있는 동안 계측 시계가 멈추므로
> "사망 → 조작 가능 3초" 에 게임 오버 대기 시간이 섞이지 않는다.
> 그 지표는 **잔기가 남은 일반 사망**의 것이다. → prompts/m1-gate.md

### 빠른 재시작 (R 키)

죽지 않고도 체크포인트에서 즉시 재시작. 성유물 갑옷을 잃은 직후 자주 쓰인다.
길게 누르기(0.5초)로 오입력 방지.

## 9.4 결과 화면 (스테이지 클리어)

```
        STAGE 1 CLEAR

  TIME       03:24        + 4,800
  ENEMIES    28/34        + 2,800
  NO-HIT     2 sections   + 4,000
  RELIC      maintained   + 10,000
  ────────────────────────────────
  TOTAL                    21,600

           RANK  A

        [계속하기]
```

- 점수는 **하나씩 순차 롤링** (총 2.5초). 아무 키나 누르면 즉시 완료
- 랭크 표시 시 스탬프 애니메이션 + 히트스톱 + 셰이크
- S랭크 달성 시 전용 팡파레 + 화면 전체 금색 파티클

> **구현 (`src/game/results.ts` · `src/ui/menus/resultsScreen.ts`)**
>
> 롤링 2.5초(줄당 0.5초 × 4 + 합계 0.5초), 건너뛰기, **랭크 스탬프**까지 구현했다.
> 도장은 2.6배에서 내리꽂히고(170ms, 뒤로 갈수록 빨라진다) → **90ms 완전 정지**
> → 감쇠 진동 260ms 순이다. 정지 구간이 히트스톱이며, 이게 없으면 그냥
> 축소 애니메이션이지 도장이 아니다. S 랭크만 금색으로 빛난다.
>
> CSS `transition` 을 쓰지 않고 프레임마다 값을 직접 준다 — 보간과 섞이면
> 정지 구간이 뭉개진다.
>
> **아직 안 한 것**: S랭크 전용 팡파레와 화면 전체 금색 파티클.
>
> 랭크 경계는 `RANK_THRESHOLDS` 에 있고 **잠정값이다.** 실제 클리어 점수
> 분포를 본 적이 없다. 시간 보너스(남은 시간 × 50)가 총점을 지배하므로,
> m1-gate 가 모으는 첫 클리어 기록으로 다시 잡아야 한다.
>
> 결과 화면을 닫으면 플레이테스트 설문이 뜬다. 보상이 먼저고 설문이 나중이다.

## 9.5 설정 메뉴

| 탭 | 항목 |
|---|---|
| **화면** | 해상도 배율 / 전체화면 / 셰이더 품질 / CRT 필터 / 흔들림 강도 / 섬광 감소 |
| **오디오** | 마스터 / BGM / SFX / 앰비언스 / 모노 출력 |
| **조작** | 키 리매핑 / 게임패드 설정 / 데드존 / 진동 |
| **접근성** | 색맹 지원 / 리듬 시각 표시 / 한손 프리셋 / 입력 토글 |
| **게임** | 난이도 / 자동 저장 / 세이브 데이터 내보내기·불러오기 |

### 세이브 데이터 관리

localStorage 기반이므로 **브라우저 데이터 삭제 시 소실 위험**이 있다.

| 기능 | 설명 |
|---|---|
| 자동 저장 | 스테이지·체크포인트 도달 시 |
| 내보내기 | 진행 상황을 Base64 코드로 출력 → 복사 |
| 불러오기 | 코드 붙여넣기로 복원 |
| 경고 | 첫 클리어 시 "브라우저 데이터를 지우면 사라집니다" 1회 안내 |

## 9.6 온보딩

**튜토리얼 화면을 만들지 않는다.** 스테이지 1이 곧 튜토리얼이다.

| 위치 | 학습 내용 | 방식 |
|---|---|---|
| S1 시작 | 이동 | 아무것도 없는 평지 + 화면 하단 키 표시 (3초 후 페이드) |
| S1 +5초 | 공격 | 느린 좀비 1마리. 맞아도 안 죽음 |
| S1 +15초 | 점프 | 건널 수밖에 없는 틈 |
| S1 +30초 | 무기 상자 | 눈에 띄는 위치에 배치 |
| S1-B 초입 | **갑옷 파괴** | 회피 가능하지만 초보는 맞도록 배치 |
| S1-B 중반 | 상단 공격 | 머리 위에만 있는 적 (다른 방법으로 못 잡음) |
| S1-B 후반 | 그림(Grimm) | 안전한 지형에서 첫 조우 |

**키 표시는 3초 후 사라지고 다시 나오지 않는다.**
막힌 플레이어를 위해 일시정지 메뉴에 조작법을 항상 두는 것으로 충분하다.

## 9.7 웹 특화 UX

| 항목 | 처리 |
|---|---|
| 첫 진입 | 로딩 진행률 + "클릭하여 시작" (오디오 컨텍스트 활성화용) |
| 탭 비활성화 | 자동 일시정지 | ← **구현됨** |
| 창 크기 변경 | 정수 배율 재계산, 레터박스 |
| 전체화면 | F11 또는 버튼. 권장 안내 1회 |
| 우클릭 | 컨텍스트 메뉴 차단 |
| 브라우저 뒤로가기 | 게임 중에는 확인 다이얼로그 |
| 모바일 접속 | "데스크톱 권장" 안내 + 그래도 플레이하면 가상 패드 제공 (M4) |
| 저사양 감지 | 30fps 미만 3초 지속 시 품질 자동 하향 + 1회 토스트 |
