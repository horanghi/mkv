## M0 — 프로토타입 (2주)

**검증 질문: 점프가 재미있는가?**

아트도, 이펙트도, 적도 없다. 회색 박스만 있다.

| 산출물 | 내용 |
|---|---|
| 픽스드 타임스텝 루프 | 60Hz 고정, 렌더 보간 |
| AABB 타일 충돌 | 스윕, 원웨이 플랫폼 |
| 랜슬 이동·점프 | 고정 궤도 + 코요테/버퍼 |
| 투사체 1종 | 창만 |
| 테스트 레벨 1개 | 점프 거리 검증용 지형 나열 |
| 디버그 오버레이 | 히트박스, 속도, 프레임 타임 |

### 종료 조건

- [x] 테스터 5명이 "점프 감각이 좋다"고 답함 — **통과 (2026-08-25)**
- [x] 고정 점프 궤도에 대해 "답답하다"는 응답 50% 미만 — **통과**
- [x] 점프 스펙 수치 확정 (초속도·중력·거리) — 실측 후 `docs/02` 갱신 완료
- [~] 60fps 안정 — 로직 비용은 확인, 렌더는 실기 확인 필요

### 구현 현황 (2026-08, 커밋 `912fdfe`)

M0-1 ~ M0-5 구현 완료. 테스트 310개, 라인 커버리지 100%.

| 실측 항목 | 값 |
|---|---|
| 점프 최고 높이 · 거리 | 62.3px (3.9타일) |
| 체공 | 34프레임 (0.567초) |
| 실제로 건널 수 있는 간격 | **3타일** (4타일은 불가) |
| 입력 지연 | 7.9ms (목표 33ms 이내) |
| 로직 비용 | 0.0006ms/틱 (예산 4ms) |
| 틱 레이트 | 120Hz 화면에서 60.0tps · 드랍 0 |

> 로직 비용은 **M0 부하 기준**이다. 플레이어 1 + 투사체 2 뿐이고 적도 이펙트도 없다.
> M1 의 30 엔티티 + 포스트FX 에서 다시 재야 한다.

**게이트 통과 (2026-08-25).** 고정 점프 궤도를 유지한다.
가변 점프 높이·공중 제어는 검토하지 않는다 — 이 판정으로 닫힌 선택지다.
`docs/02` 의 점프 수치는 이제 **확정 스펙**이며, 바꾸려면 게이트를 다시 통과해야 한다.

> **여기서 실패하면 기획을 고친다.**
> 가변 점프 높이 도입, 공중 제어 소폭 허용 등을 검토한다.
> 이 게임의 모든 것이 점프 위에 서 있으므로 여기서 타협하면 안 된다.

## M1 — 버티컬 슬라이스 (6주)

**검증 질문: 이 게임이 화려한가? 죽어도 다시 하고 싶은가?**

스테이지 1 하나만, 하지만 **최종 품질로** 완성한다.

| 영역 | 산출물 |
|---|---|
| 게임플레이 | 무기 3종(창·단검·도끼), 갑옷 3단계, 성유물 1종 | ← 보물상자로 획득 가능 |
| 레벨 | S1 완성 (2섹션 + 보스룸), 체크포인트 |
| 적 | 좀비, 그림, 까마귀 |
| 보스 | 캐른 (3페이즈) |
| 비주얼 | **포스트 프로세싱 스택 전체** — 블룸, 광원, 색수차, 비네트 |
| 연출 | **갑옷 파괴 연출 완성** + 사망 연출 |
| 오디오 | S1 BGM (4스템 적응형), 보스 BGM, SFX 40종 | ← 합성으로 전부 구현 |
| UI | HUD, 일시정지, 사망→재시작, 결과 화면 | ← 전부 구현됨 |
| 도구 | 스테이지 워프, 프레임 스텝, 슬로우모션 | ← 전부 구현됨 |

### 종료 조건

- [ ] **사망 후 즉시 재시도율 90% 이상** — 계측기 완비, 테스터 투입 대기
- [ ] "죽는 연출이 좋았다" 응답 70% 이상 — 빌드 안에서 묻는다, 테스터 투입 대기
- [x] 사망→조작 가능까지 3초 이내 — **1.75초** (실측, 틱 정밀)
- [ ] S1 첫 클리어 시도 횟수 평균 8~15회 — 계측기 완비, 테스터 투입 대기
- [x] 초기 로드 8MB 이내 — **0.17MB** (프로덕션 빌드 gzip)
- [ ] 중급 노트북 1080p 60fps 유지율 95% — 계측기 완비, 실기 필요
      (프레임 비용 실측: p95 1.5ms / 예산 16.67ms → docs/06 6.9)

> 여섯 항목 모두 **빌드가 직접 잰다.** 남은 것은 사람을 앉히는 일뿐이다.
> 조작적 정의와 결과 수집 방법은 `prompts/m1-gate.md` 의 "어떻게 재는가" 를 따른다.

**미완**: BGM·SFX **음원 파일** (합성으로 대체 중 — 믹스 로직은 최종 설계대로 동작한다),
캐른 아트 패스(그레이박스 등급), 보스룸 쇠창살, S랭크 팡파레·금색 파티클.

**화면에 남은 그레이박스는 없다.** 배경·잡몹·보스가 전부 스프라이트로 그려진다.
**무음 구간도 없다.** 적응형 5스템 BGM 이 흐른다.

**남은 것은 사람의 판단이다.** 테스터에게 빌드를 주고 두 가지를 본다 —
죽은 뒤 바로 다시 하는가, 죽는 연출을 좋아하는가.
숫자는 빌드가 세고 있으므로, 테스터는 **결과 복사** 버튼만 눌러 주면 된다.

> **M1이 이 프로젝트의 진짜 관문이다.**
> 여기서 "화려하다"는 반응이 안 나오면 아트 디렉션을 재검토한다.
> 스테이지를 늘리기 전에 반드시 이 검증을 통과해야 한다.

### 종료 조건

- [ ] S1~S4 연속 플레이 가능
- [ ] 난이도 곡선 검증 (구간별 사망 횟수 목표 범위 내)

**무기 각성 21조합은 M2 최대 리스크다.**
전부 고유 에셋으로 만들면 일정이 무너진다. 반드시 팔레트 스왑 + 파티클 변경으로 처리하고,
정말 다른 스프라이트가 필요한 것은 5개 이하로 제한한다.

## M3 — 후반 스테이지 (10주)

**목표: 8스테이지를 전부 통과할 수 있게 만든다.**

| 영역 | 산출물 |
|---|---|
| 레벨 | S5 갱도, S6 감옥, S7 절벽, S8 왕좌 |
| 보스 | 노커, 갈라드, 에일로, 아스모데우스 |
| 신규 시스템 | **시야 제한**(S5), **외력 바람**(S7) |
| 오디오 | S5~S8 BGM, 보스 4곡 |

### 종료 조건

- [ ] S1~S8 연속 플레이 가능
- [ ] S5 에서 성유물 갑옷 유무에 따른 체감 차이가 응답으로 확인됨
- [ ] S7 바람이 "예고 없이 당했다"는 응답 10% 미만
- [ ] 8스테이지 완주 플레이타임 2시간 ±30분

### 리스크

**S5(시야)와 S7(외력)은 이 프로젝트에서 처음 시도하는 두 기믹이다.**
둘 다 "안 보여서/못 피해서 죽었다"로 흐르기 쉽고, 그러면 재시도율이
무너진다. 각 스테이지 첫 섹션을 먼저 만들어 **M3 초반에 따로 검증**한다.
공정성 장치(인광 이끼, 3초 바람 전조)가 충분한지가 판정 기준이다.

## M3.5 — 환마계 (6주)

**목표: 2회차를 새 콘텐츠로 만든다.**

| 영역 | 산출물 |
|---|---|
| **환마계** | 8스테이지 셰이더 변환 + 배치 재구성 |
| 진 최종보스 | 루시안 (5페이즈) |
| 환영 무기 | 7종 |
| 엔딩 | 1회차 엔딩, 진 엔딩 |
| 오디오 | 환마계 BGM, 루시안 |

### 종료 조건

- [ ] 진 엔딩까지 완주 가능
- [ ] 완주 플레이타임 4시간 ±45분 (8스테이지 × 2회차)
- [ ] 환마계가 "새 콘텐츠처럼 느껴진다" 응답 60% 이상
- [ ] 십자가 게이트에서 막히는 플레이어 0%

### 리스크

**환마계가 "그냥 색만 바뀐 반복"으로 느껴지면 이 설계는 실패다.**
셰이더 변환만으로는 부족할 수 있다. M3.5 초반에 S1 환마계 버전을 먼저 만들어
**조기에 검증**하고, 부족하면 지형 재배치 비중을 늘린다.

**8스테이지 × 2회차는 16판이다.** 마계촌 계보의 구조가 그렇지만, 반복이
길어질수록 "색만 바뀐 반복" 위험도 커진다. 환마계 배치 재구성 비중을
6개 계획 때보다 높게 잡아야 한다.
