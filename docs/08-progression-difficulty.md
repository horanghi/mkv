# 08. 진행 & 난이도

## 8.1 전체 진행 구조

```
[타이틀]
   ↓
[1회차] S1 → S2 → S3 → S4 → S5 → S6 → 아스모데우스 격파
   ↓
"이 마을은 처음부터 존재하지 않았다"
   ↓
[2회차 · 환마계] S1★ → S2★ → S3★ → S4★ → S5★ → S6★ → 루시안 격파
   ↓
[진 엔딩]
```

| 구간 | 목표 시간 |
|---|---|
| 1회차 (첫 플레이) | 90~150분 |
| 2회차 환마계 | 60~90분 |
| 진 엔딩 도달 총합 | 약 3시간 |
| 100% 완주 (전 유물·전 S랭크) | 8~12시간 |

## 8.2 환마계 (2회차)

**원작 계승**: 최종보스를 쓰러뜨려도 끝나지 않는다. 그것은 환영이었다.

### 무엇이 바뀌는가

| 항목 | 1회차 | 환마계 |
|---|---|---|
| 색채 | 스테이지 고유 팔레트 | **HSV 반전 + 명도 반전** |
| 진행 방향 | 좌 → 우 | S2·S4·S6은 **우 → 좌** (지형 미러링) |
| 적 배치 | 학습 가능한 배치 | 재구성 — 익숙한 위치에 다른 적 |
| 적 밀도 | 스테이지별 2.0~3.5 | **4.0** (동시 최대 10) |
| 신규 기믹 | — | 중력 반전 구간, 공간 접힘, 지연 잔상 |
| 그림(Grimm) | 스테이지당 4~8마리 | **2배**, 일부는 즉시 추적 개시 |
| 보스 | 기본 3~4페이즈 | **+1 페이즈** (환영 페이즈) |
| 무기 | 7종 | + **환영 무기** 7종 (그림자 버전) |
| 제한 시간 | 5분 | 4분 |

### 환영 무기

각 무기의 그림자 버전. 환마계 전용 상자에서만 획득.

| 원본 | 환영 버전 |
|---|---|
| 창 | **그림자 창** — 관통, 적을 뚫을 때마다 데미지 +3 |
| 단검 | **잔상 단검** — 던진 위치에 1초 후 두 번째 단검이 자동 발사 |
| 횃불 | **한기 횃불** — 화염 대신 냉기 장판 (적 이동 정지) |
| 도끼 | **처형 도끼** — HP 25% 이하 적 즉사 |
| 십자가 | **역십자** — 데미지 2배, 대신 랜슬도 발사 시 미세 반동 데미지 |
| 원반 | **무한 원반** — 반사 무제한, 30초 후 소멸 |
| 망치 | **파쇄 망치** — 지형 파괴 가능 (숨겨진 통로 개방) |

### 십자가 게이트 (원작 계승)

**루시안에게는 십자가 계열 무기만 데미지가 들어간다.**

원작에서 이 규칙은 악명 높은 불친절이었다. 우리는 세 겹의 안전장치를 둔다:

1. 환마계 S6 진입 시 벽화에 십자가 문양이 크게 그려져 있음
2. 최종 구역 문에 "성물 없이는 열리지 않는다" 시각 표시
3. 십자가 미보유 상태로 도달 시 **직전 체크포인트에 십자가 상자 강제 스폰**

전통은 지키되, 플레이어를 함정에 빠뜨리지는 않는다.

## 8.3 난이도 곡선

### 구간별 목표 사망 횟수 (첫 플레이 기준)

| 구간 | 목표 사망 | 의미 |
|---|---|---|
| S1-A | **0** | 튜토리얼. 죽을 수 없어야 한다 |
| S1-B | 1~2 | 첫 갑옷 파괴 연출 경험 |
| S1 보스 | 0~1 | 보스 문법 학습 |
| S2 | 3~5 | 속도 압박 도입 |
| S3 | 5~8 | 빙판 + 고정 점프 = 첫 벽 |
| S4 | 4~7 | 압박 지속 |
| S5 갱도 | 6~9 | 시야 제한. 갑옷이 자원임을 몸으로 배운다 |
| S6 감옥 | 8~12 | 세로 스크롤 |
| S7 절벽 | 7~10 | 외력. 뛰기 전에 읽는 법을 시험한다 |
| S8 왕좌 | 10~15 | 총집합 |
| 환마계 전체 | 35~55 | 숙련 전제 |

**총 사망 예상: 1회차 44~69회.** (기준: 기사 난이도)
이 수치를 크게 벗어나면 밸런스를 조정한다. 특히 S1에서 죽는 플레이어가 30%를 넘으면
튜토리얼 실패로 간주하고 재설계한다.

> **8스테이지로 늘리면서 곡선을 다시 폈다.** 6개일 때 S5(감옥)가 혼자 지고 있던
> 최고 난이도 부담을 S5~S8 넷이 나눠 진다. 봉우리는 여전히 마지막(S8)이지만,
> 중반(S5 갱도)에 **성격이 다른 벽**을 하나 세워 실력이 아니라 이해를 요구한다.

### 난이도 검증 기준

| 지표 | 합격선 |
|---|---|
| S1 클리어율 (첫 세션) | 85% 이상 |
| S3 도달률 | 60% 이상 |
| S5 도달률 | 40% 이상 |
| S8 도달률 | 20% 이상 |
| 1회차 클리어율 | 15% 이상 |
| 환마계 클리어율 | 5% 이상 |
| 사망 후 즉시 재시도율 | 90% 이상 ← **가장 중요한 지표** |

**"사망 후 재시도율"이 모든 것을 말한다.**
이 수치가 낮으면 게임이 어려운 게 아니라 **불공정하게 느껴진다는 뜻**이다.

## 8.4 난이도 3단계

원작에는 없었지만, 웹 플랫폼에서는 필요하다.
**단, 난이도를 낮추는 것이 아니라 "관용"을 조절한다.**

| 모드 | 대상 | 잔기 | 제한 시간 | 체크포인트 | 적 밀도 | 그림 | 노히트 |
|---|---|---|---|---|---|---|---|
| **종자 (Squire)** | 입문자 | 5 | 8분 | 3 | 100% | 70% | ×1 |
| **기사 (Knight)** | 기본 | 3 | 5분 | 2 | 100% | 100% | ×1 |
| **성기사 (Paladin)** | 숙련자 | 2 | 4분 | 1 | 125% | 100% | ×2 |

**세 단계다.** 관용 축(잔기·시간·체크포인트)이 단조롭게 줄어드는 것이
세 단계의 정의이고, 테스트가 그 단조성을 강제한다.

> **원코인(참회)은 난이도가 아니다.** 잔기 1·컨티뉴 없음은 관용 축 위의 한 점이
> 아니라 **세 단계 어디에나 얹을 수 있는 도전 모디파이어**다. 난이도 축에 끼워
> 넣으면 "성기사보다 어려운 단계"로 오해되는데, 실제로는 종자에서도 원코인을
> 걸 수 있어야 한다. 해금 요소로 분리한다 → 8.5

### 구현 (`src/game/difficulty.ts`)

- `applyDifficulty(balance, id)` — **잔기와 제한 시간만** 바꾼다
- `applyDifficultyToStage(stage, id)` — 체크포인트 수, 그림 수, 적 밀도
- 체크포인트는 **앞에서부터 남긴다.** 뒤만 남기면 성기사에서 스테이지 초반이
  통째로 무체크포인트가 되어 관용이 아니라 형벌이 된다 → 4.2 원칙 4
- 적 밀도는 **검증된 좌표 옆(2타일)에만** 복제한다. 임의 좌표는 레벨 배치
  규칙(착지 지점·궤도 위)을 깨뜨릴 수 있다 → `stage1.test.ts`
- 이동·점프·중력은 **어떤 난이도에서도 같다.** 고정 점프 궤도는 비협상
  원칙이라 난이도로 흔들면 같은 게임이 아니게 된다 (테스트로 고정)
- 설정은 `localStorage` 에 남고, 바꾸면 판이 다시 시작된다 — 도중에
  체크포인트 수가 바뀌면 이미 지나온 구간의 규칙이 달라져 기록이 뒤섞인다
- 고르는 곳은 일시정지 메뉴다 → docs/09 9.6

### 설계 원칙

| 하는 것 | 안 하는 것 |
|---|---|
| 관용 장치 조절 (체크포인트, 시간, 잔기) | 적 HP·데미지 수치 조작 |
| 적 밀도 조절 | 패턴 삭제·단순화 |
| 그림 출현 빈도 조절 | 보스 페이즈 생략 |
| — | **이동·점프·중력 수치 조작** |

**"쉬운 모드로 클리어해도 같은 게임을 했다"** 는 감각이 유지되어야 한다.
모드 간 격차는 실력이 아니라 **인내심의 차이**로 설계한다.

### 모드 변경

- 언제든 변경 가능 (스테이지 도중 포함)
- 낮은 모드로 변경 시 **경고나 페널티 없음**
- 단, 도전 과제와 랭킹은 모드별로 분리 기록
- 진 엔딩은 종자 모드에서도 도달 가능 (게이트하지 않는다)

## 8.5 영구 진행 요소

**게임플레이를 쉽게 만드는 영구 강화는 넣지 않는다.**
스테이지 클리어형 게임에서 영구 강화는 난이도 곡선을 무너뜨린다.

대신 **수집·표현 요소**와 **도전 모디파이어**만 영구화한다.

### 도전 모디파이어

난이도 축과 직교한다. 세 단계 어디에나 얹을 수 있다.

| 모디파이어 | 내용 | 해금 |
|---|---|---|
| **참회 (Penance)** | 원코인 — 잔기 1, 컨티뉴 없음 | 아무 난이도로 1회차 클리어 |
| **금욕 (Abstinence)** | 무기 상자 미출현 (창만) | 참회 클리어 |
| **맹세 (Vow)** | 노히트 강제 — 한 대라도 맞으면 즉시 실패 | 금욕 클리어 |

기록은 **모디파이어 조합별로 분리**한다. "성기사 + 참회" 와 "종자 + 참회" 는
다른 기록이며, 어느 쪽도 다른 쪽의 상위가 아니다.

| 요소 | 해금 조건 | 효과 |
|---|---|---|
| 갑옷 스킨 (8종) | 각종 도전 과제 | 외형만 변경 |
| 무기 스킨 | 무기별 처치 수 | 외형만 변경 |
| 갤러리 | 유물 조각 12개 수집 | 아트워크 열람 |
| 사운드 테스트 | 유물 조각 12개 수집 | BGM 청취 |
| 보스 러시 모드 | 1회차 클리어 | 보스 7체 연속 도전 |
| 랜슬 이외 캐릭터 | 진 엔딩 클리어 | **갈라드 플레이어블** (다른 점프 스펙) |

### 갈라드 플레이어블 (포스트 게임)

진 엔딩 이후 해금. 랜슬과 다른 규칙으로 플레이한다.

| 항목 | 랜슬 | 갈라드 |
|---|---|---|
| 점프 | 고정 궤도 | **공중 제어 가능** (단, 점프 높이 낮음) |
| 공격 | 투척 | **근접 검격** (리치 짧음, 데미지 높음) |
| 갑옷 | 3단계 | 2단계 (성유물 없음) |
| 성흔 | 3종 | 1종 (돌진) |

전혀 다른 플레이 감각을 제공해 재플레이 가치를 만든다. **M4 이후 확장 콘텐츠로 분리 가능.**

## 8.6 접근성

| 옵션 | 기본 | 설명 |
|---|---|---|
| 화면 흔들림 강도 | 100% | 0~100% 조절 (전정기관 민감) |
| 섬광 감소 | OFF | 화이트아웃·번개 강도 50% 제한 |
| 색맹 지원 | OFF | 적/투사체에 형태 마커 추가 (3종 프리셋) |
| 리듬 시각 표시 | ON | S3 종소리 시각화 |
| 키 리매핑 | 제공 | 전체 재배치 가능 |
| 한손 조작 프리셋 | 제공 | |
| 입력 홀드 → 토글 | OFF | 웅크리기 등 |
| 자동 전진 보조 | OFF | 강제 스크롤 구간에서 이동 자동화 |

**섬광 감소는 반드시 넣는다.** 이 게임은 화이트아웃과 번개를 자주 쓴다.
광과민성 발작 위험은 접근성이 아니라 **안전** 문제다.
