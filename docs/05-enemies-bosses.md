# 05. 적 & 보스

## 5.1 적 설계 원칙

1. **모든 적은 한 문장으로 설명된다** — "이 적은 ○○한다"가 안 되면 설계를 다시 한다
2. **예고 없는 공격은 없다** — 모든 공격에 최소 12프레임(200ms) 선행 모션
3. **적의 역할은 지형이다** — 적 단독으로 위협적이기보다, 지형과 결합해 압박을 만든다
4. **화면 밖에서 죽이지 않는다** — 스폰은 화면 가장자리 32px 밖에서만

### 그림 (Grimm) — 시리즈 전통의 트라우마

원작 레드 아리마의 계승자. **이 게임에서 가장 미움받아야 할 적.**

| 상태 | 행동 |
|---|---|
| 대기 | 벽·천장에 붙어 정지 |
| 활성 | 랜슬이 반경 120px 진입 시 이륙 |
| 추적 | 사인파 궤도로 랜슬 위치를 향해 이동, 속도 90 px/s |
| 착지 | 지면 도달 시 3초 정지 (유일한 확정 공격 타이밍) |
| 재이륙 | 다시 추적 |

**설계 의도**: 고정 점프 궤도와 최악의 상성. 공중에서 만나면 회피할 수 없다.
따라서 플레이어는 **점프 전에 그림의 위치를 반드시 확인**하게 된다.
이것이 이 게임의 사고 루프를 강제하는 핵심 장치다.

**공정성 장치**: 그림은 절대 화면 밖에서 스폰되지 않는다. 반드시 화면 안에서 대기 상태로 먼저 보인다.

## 5.3 보스 설계 원칙

| 원칙 | 내용 |
|---|---|
| 페이즈 3개 | HP 100~60% / 60~25% / 25~0%. 페이즈마다 패턴 추가 |
| 패턴 4~6개 | 무작위가 아닌 **가중치 순환** — 같은 패턴 연속 최대 2회 |
| 선행 모션 명확 | 각 패턴마다 고유한 준비 자세 (실루엣만으로 구분 가능) |
| 무기 무관 클리어 | 어떤 무기로도 격파 가능 (루시안 제외) |
| 노히트 가능 | 모든 패턴에 확정 회피 루트 존재 |
| 목표 시간 | 첫 도전 3~5분, 숙련 시 60~90초 |

## 5.4 보스 7종

### S1 · 캐른 (Cairn) — 시체 골렘
**HP 300 · 튜토리얼 보스**

시체와 묘비가 뭉쳐진 거대한 덩어리. 느리고 크다.

| 페이즈 | 패턴 |
|---|---|
| 1 | 팔 내려찍기(예비 30f) · 묘비 투척(포물선 2개) |
| 2 | + 지면 강타 → 낙석 3개 · 좀비 3마리 소환 |
| 3 | + 몸통 분해 → 파편 4개가 개별 추적 (재결합 후 원래 패턴) |

**약점**: 가슴의 발광 코어. 다른 부위 피격 시 데미지 50%.
**격파 연출**: 코어 파괴 → 400ms 히트스톱 → 화이트아웃 → 몸통이 시체 단위로 흩어지며 무너짐.

### S2 · 모르그 & 마그 (Morg & Mag) — 쌍둥이 처형인
**HP 각 220 · 2체 동시**

거대한 도끼를 든 붉은 처형인 둘. 한 쪽이 죽으면 나머지가 격노한다.

| 상태 | 행동 |
|---|---|
| 양쪽 생존 | 교대 공격 — 한 쪽이 돌진, 한 쪽이 도끼 투척 |
| 한쪽 사망 | 생존자 **격노**: 공격 속도 1.6배, 화염 부여, 신규 패턴 2개 |

**설계 의도**: "약한 쪽을 먼저 잡는다"는 상식을 배신한다. HP를 **동시에** 깎는 것이 정답.
**공정성**: 첫 조우 시 두 처형인의 HP 게이지가 나란히 표시되어 힌트를 준다.

---

### S3 · 비르나 (Byrna) — 얼음 마녀
**HP 340 · 리듬 보스**

4초마다 울리는 종에 맞춰 공격한다. **BGM 박자 = 패턴 타이밍.**

| 종 타이밍 | 패턴 (순환) |
|---|---|
| 1타 | 고드름 낙하 (경고 그림자 표시) |
| 2타 | 냉기 파동 (점프로 회피) |
| 3타 | 순간이동 후 근접 |
| 4타 | 화면 전체 서리 → 지면 빙판화 (지속) |

**설계 의도**: 눈이 아니라 **귀로 싸우는 보스.** 소리를 끄면 눈에 띄게 어려워진다.
**접근성**: 청각 의존 완화를 위해 종 울림마다 화면 가장자리 시각 펄스 제공 (기본 ON).

### S4 · 뮤크 (Muck) — 늪 히드라
**HP 머리당 160 × 3**

머리 3개가 각각 독립 행동. 모두 처치해야 격파.

| 머리 | 성격 |
|---|---|
| 좌 | 독액 3연발 (포물선) |
| 중 | 돌진 물기 (최장 리치) |
| 우 | 독 구름 생성 (지역 봉쇄) |

머리 하나 처치 시 → 남은 머리들이 **부활 시도** (8초 후 절반 HP로 부활).
부활 전에 다른 머리를 처치해야 하는 시간 압박 구조.

**약점**: 수위가 최고조일 때 몸통이 드러난다. 몸통 피격 시 모든 머리에 데미지.

### S5 · 갈라드 (Galahad) — 거울 기사
**HP 400 · 서사의 정점**

랜슬과 같은 성유물 갑옷을 입은 처형된 성기사.
**플레이어가 현재 들고 있는 무기를 그대로 사용한다.**

| 페이즈 | 변화 |
|---|---|
| 1 | 랜슬과 동일한 이동·점프·공격 규칙 사용 |
| 2 | 갑옷이 부서지며(플레이어와 같은 연출) 속도 1.4배 |
| 3 | 속옷 상태 — 필사적, 패턴 예측 불가, 근접 위주 |

**설계 의도**: 대사 한 줄 없이 "성기사의 말로"를 보여준다.
플레이어가 갑옷을 잃는 연출을 적에게 그대로 적용해, 그 연출의 의미를 뒤집는다.

**격파 연출**: 갈라드가 무릎 꿇고 랜슬을 올려다본다. 3초 정적. 그 후 재가 되어 흩어진다.
**보상**: 갈라드의 투구 — 착용 시 성유물 갑옷 획득률 상승 (장식 슬롯).

### S6 · 아스모데우스 (Asmodeus) — 대마왕
**HP 700 · 4페이즈 · 1회차 최종**

| 페이즈 | 무대 | 패턴 |
|---|---|---|
| 1 | 왕좌 앞 | 화염 브레스 · 손톱 휩쓸기 · 소환(용암새 4) |
| 2 | 공중 부양 | 화면 전체 낙하물 · 추적 화염구 · 돌진 |
| 3 | **무대 붕괴** — 발판 3개만 남음 | 발판 파괴 공격 · 용암 상승 |
| 4 | 진짜 모습 (화면 절반 크기) | 전 패턴 고속화 + 화면 전체 광역기 (안전 지대 1곳) |

**연출 요구**: 페이즈 전환마다 **화면 전환 컷** (0.8초). 이 게임 최대의 스펙터클 구간.
**격파 후**: 화면이 일그러지며 → *"이 마을은 처음부터 존재하지 않았다."* → 환마계 진입.

### ★ 루시안 (Lucian) — 진 최종보스
**HP 900 · 5페이즈 · 2회차 전용**

**십자가를 들고 있지 않으면 데미지가 들어가지 않는다.** 원작 전통 계승.

| 페이즈 | 특징 |
|---|---|
| 1 | 아스모데우스의 패턴을 그대로 사용 (환영) |
| 2 | S1~S5 보스의 패턴을 무작위로 차용 |
| 3 | **화면 반전** — 조작 좌우 반전 (30초) |
| 4 | 랜슬의 그림자 3체 소환 (플레이어 조작을 1초 지연 모방) |
| 5 | 진짜 모습 — 화면 전체, 패턴 없음. **십자가 광선으로 정면 대결** |

**페이즈 5 설계**: 회피가 아니라 **버티기**. 랜슬과 루시안이 광선을 맞대고 밀어내는 구조.
연타 입력으로 게이지를 밀어내며, 실패 시 즉사. 게임 전체의 클라이맥스.
