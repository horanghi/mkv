# 스프라이트 생성기

대형 스프라이트(보스)를 손으로 세지 않고 만들기 위한 도구.
캐른(`docs/12-sprites.md` 12.10)이 이걸로 만들어졌다.

```bash
cd tools/sprite && python3 cairn.py && python3 viewer.py   # → docs/cairn.html
```

## 왜 필요했나

32×32 캐릭터는 손으로 찍어도 되지만 56×52 보스는 다르다.
이전 도트 작업에서 실패한 원인이 전부 같았다.

| 실패 | 원인 |
|---|---|
| 행 길이가 어긋나 실루엣이 깨짐 | 손으로 세다 틀림 |
| "냉장고" 실루엣 | 폭이 여러 행 연속 같은 값 |
| 팔이 몸에서 떨어져 보임 | 파츠 오프셋이 몸통과 안 겹침 |
| 팔이 모래시계·지느러미가 됨 | 모든 행을 중앙 정렬 |

## 두 가지 규칙

**1. 정렬 축.** `blob(..., align='left')` 는 왼쪽 면을 곧게 세운다.
팔처럼 한쪽이 몸통에 붙는 부위를 중앙 정렬하면 위아래가 굵고 가운데가 잘록한
모래시계가 되어, 몸에 붙은 팔이 아니라 옆에 놓인 기둥으로 읽힌다.

**2. 실루엣과 질감을 분리한다.** 실루엣은 읽히게 매끈히 두고 덩어리감은
내부 텍스처(`stamp`)로 준다. 실루엣 자체를 들쭉날쭉하게 만들면
아웃라인이 조각나 노이즈가 된다.
