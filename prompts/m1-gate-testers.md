# 테스터에게 보낼 것

메신저에 그대로 붙여넣는 글이다. **다섯 명이 필요하다.**

아래 "보내는 글" 만 복사한다. 그 위아래는 우리끼리 보는 주의사항이다.

## 보내기 전에

- **무엇을 재는지 말하지 않는다.** "죽고 나서 바로 다시 하는지 본다"고 알리면
  그 순간 지표가 죽는다 — 사람은 관찰되는 행동을 바꾼다. 게이트 표는 우리만 본다.
- **난이도를 건드리지 말라고 먼저 말한다.** 바꾸면 그때까지의 기록이 사라진다.
- 중급 사양 노트북에서 돌려 달라고 한다. 게이밍 PC 만 모이면 60fps 항목이 거짓이 된다.
- 링크는 로그인이 필요 없다. 계정도, 설치도 없다.
- **아래 링크 하나로만 보낸다.** 민찬 게임랜드에도 같은 게임이 올라가 있는데,
  그쪽은 손으로 빌드해 넣는 스냅샷이라 이 링크와 다를 수 있다. 다르면 서로
  다른 게임을 잰 것이 된다. (꾸러미의 `build` 가 갈리면 `npm run gate` 가 알려준다.)
- **폰으로 열면 조작이 없다.** 게임이 안내를 띄우긴 하지만, 글에서 먼저 말한다 —
  폰에서 열었다 닫으면 사망이 없어 결과를 보낼 방법조차 없다.

## 보내는 글

---

만들고 있는 게임입니다. 30분쯤 해보고 알려주세요.

**https://mkv-five.vercel.app**

브라우저에서 바로 됩니다. 설치도 로그인도 없습니다.
**노트북이나 데스크톱에서 열어 주세요** — 키보드로 하는 게임이라 폰에서는 못 움직입니다.

**조작**
```
← →  이동        Z  점프
X    던지기      ↓  웅크리기
Esc  일시정지    R  처음부터
```

**부탁**

- 일시정지 메뉴의 **난이도는 그대로 두세요.** 바꾸면 기록이 처음부터 다시 시작됩니다.
- 어렵습니다. 원래 그런 장르입니다 — 하기 싫어지면 그만두셔도 됩니다.
  억지로 참고 계속하지 마세요. 그것도 저희가 알아야 할 정보입니다.
- 탭을 닫았다 다시 열어도 이어집니다. 한 번에 다 하지 않으셔도 됩니다.

**끝나면**

화면 오른쪽 아래 **`결과 보내기`** 버튼을 누르고, 두 개 질문에 답한 뒤
**`결과 복사`** 를 눌러서 나온 것을 저한테 그대로 보내주세요.

개인을 알아볼 수 있는 것은 담기지 않습니다. 어디서 몇 번 죽었는지,
프레임이 얼마나 나왔는지 같은 숫자뿐입니다.

## 받은 뒤

붙여넣기 그대로 파일에 모아서:

```
npm run gate -- results.txt
```

사람이 쓴 글이 섞여 있어도 된다 — JSON 만 골라낸다.
판정 규칙은 `prompts/m1-gate.md` "합칠 때" 를 본다.

## 다섯 명이 안 모이면

판정은 `표본부족` 으로 나온다. **그건 통과가 아니다.**
세 명 결과가 다 좋아도 M2 로 넘어가지 않는다 — 재시도율 90% 는
세 명으로 말할 수 있는 숫자가 아니다.
