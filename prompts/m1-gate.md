# M1 게이트 — 이 프로젝트의 진짜 관문

**스테이지를 늘리기 전에 반드시 통과한다.** 여기서 실패한 채로 M2에 들어가면
같은 결함을 6개 스테이지에 복제하게 된다.

## 측정 항목

추측하지 말고 계측한다.

| 지표 | 합격선 | 의미 |
|---|---|---|
| **사망 후 즉시 재시도율** | **≥ 90%** | 가장 중요. 미달이면 어려운 게 아니라 불공정한 것 |
| 60fps 유지 | 중급 노트북에서 95% 프레임 | |
| 첫 클리어 시도 횟수 | 8~15회 | 5회 미만이면 쉽고, 25회 초과면 이탈 |
| "죽는 연출이 좋았다" | 70% 이상 | 이 게임의 판매 포인트 |
| 초기 로드 | 8MB 이하 | 웹을 고른 이유 |
| 사망 → 조작 가능 | 3초 이하 | |

## 재시도율이 낮을 때

난이도를 낮추기 전에 원인을 분리한다.

| 증상 | 원인 | 조치 |
|---|---|---|
| 같은 지점에서 반복 사망 후 이탈 | 그 구간이 판독 불가 | 레벨 수정 (카메라 선행, 예고 신호) |
| 죽고 나서 화면을 오래 봄 | 재시작 마찰 | 연출 단축, 페이드 축소 |
| 무엇에 죽었는지 모름 | 시각 신호 부족 | 적 대비 강화, 투사체 크기 |
| 그림에게만 죽음 | 스폰 규칙 위반 | 화면 밖 스폰 여부 재점검 |

## 통과 후

M2로 넘어가되, 이 지표들을 각 스테이지마다 다시 측정한다.
M1에서 세운 기준선이 이후 모든 밸런싱의 기준이 된다.
