# 구현 프롬프트 — 인덱스

파일 하나가 곧 프롬프트다. **통째로 복사해서 던지면 된다.**

## 사용법

```
1. 새 세션 시작
2. GOAL.md 가 로드되어 있는지 확인 (CLAUDE.md 가 자동으로 읽힌다)
3. prompts/ 의 파일을 순서대로 하나씩 던진다
4. Done 조건을 통과해야 다음으로 넘어간다
```

**한 번에 하나씩.** 묶어서 주면 에이전트가 앞 단계를 대충 끝내고 넘어간다.
게이트 파일에서 멈추는 것이 이 구조의 핵심이다.

## 프롬프트 작성 원칙

새 프롬프트를 추가할 때 지킬 것.

| 원칙 | 이유 |
|---|---|
| 읽을 문서를 명시한다 | 에이전트가 수치를 지어내는 것을 막는다 |
| 수치는 문서를 참조하게 한다 | 프롬프트에 복붙하면 `docs/` 와 갈라진다 |
| "하지 말 것"을 함께 쓴다 | 고정 점프 궤도처럼 선의로 고쳐버리기 쉬운 것 |
| Done 조건을 측정 가능하게 | "잘 작동한다"가 아니라 "재시도율 90%" |
| 한 프롬프트 = 한 관심사 | 묶으면 앞 단계를 대충 끝낸다 |

## 세션 운용 — 컨텍스트 관리

구현 세션은 **이 기획 세션과 컨텍스트를 공유하지 않는다.** 새 세션은 항상 0에서 시작한다.
다만 구현 중 컨텍스트가 차오르는 것은 별개 문제이고, 아래 규칙으로 관리한다.

### 세션 시작 오버헤드

| 항목 | 크기 | 비고 |
|---|---|---|
| 글로벌 CLAUDE.md + rules | ~6-8k 토큰 | 자동 로드 |
| 프로젝트 CLAUDE.md | ~1.5k | 자동 로드 |
| GOAL.md | ~0.8k | CLAUDE.md 지시로 로드 |
| 프롬프트 1개 | ~0.6k | |
| **소계** | **~10k** | 작업 시작 전 |

### 참조 문서 비용

| 문서 | 크기 | 주의 |
|---|---|---|
| `docs/12-sprites.md` | **~10k 토큰** | 도트 매트릭스 때문에 가장 무겁다 |
| `docs/04-stages.md` | ~5k | |
| `docs/05-enemies-bosses.md` | ~5k | |
| `docs/02-core-mechanics.md` | ~4k | |
| 나머지 | 2-4k | |

**`m1-5-stage1`은 문서 3개를 참조하므로 시작만으로 30k를 쓴다.** 단독 세션이 필수다.

### 권장 세션 분할

| 세션 | 프롬프트 | 이유 |
|---|---|---|
| 1 | m0-1 + m0-2 | 둘 다 가볍고 연속적 |
| 2 | m0-3 | 테스트 작성이 길다 |
| 3 | m0-4 + m0-5 | 실측 튜닝 반복 |
| 4 | m1-1 | docs/12 참조 — 단독 |
| 5 | m1-2 + m1-3 | 갑옷 상태와 연출은 같은 맥락 |
| 6 | m1-4 | 셰이더 디버깅 반복 |
| 7-8 | m1-5 | **둘로 쪼갠다** — 레벨 / 보스 |
| 9 | m1-6 | |
| 이후 | 프롬프트 1개 = 세션 1개 | M2부터는 개별 작업량이 크다 |

### 임계치

`~/.claude/rules/common/performance.md` 규칙을 따른다 — **컨텍스트 마지막 20%는 쓰지 않는다.**

| 상황 | 조치 |
|---|---|
| 50% 도달 | 현재 프롬프트를 마무리하고 커밋 |
| 60% 도달 | 새 세션 준비. 진행 상황을 코드와 문서에 반영 |
| 80% 초과 | 대규모 편집·다중 파일 리팩터링 금지 |

### 컨텍스트를 아끼는 방법

**1. 매트릭스를 코드로 먼저 옮긴다.** `m1-1` 착수 전에 `docs/12-sprites.md`의 도트
데이터를 `src/data/sprites.ts`로 변환해두면, 이후 세션은 문서 10k 대신 임포트 한 줄이면 된다.

**2. 프롬프트가 지정한 문서만 읽힌다.** 각 프롬프트에 "Read X first"를 명시한 이유가
이것이다. `docs/`를 통째로 읽히지 않는다.

**3. 세션 인계는 파일로 한다.** 대화를 이어받게 하지 말고, 커밋된 코드와 갱신된 문서가
상태를 전달하게 한다. 그래서 "코드를 고치면 `docs/`의 표도 함께 고친다"가 규칙인 것이다.
